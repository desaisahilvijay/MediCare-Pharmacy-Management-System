📋 QUICK START GUIDE FOR YOUR FRIEND:

OPTION 1 - EASIEST (One-Click Setup):
=====================================
Windows Users:
- Double-click "setup.bat" file
- Wait for installation to complete
- Browser will open automatically

Mac/Linux Users:
- Double-click "setup.sh" file
- Or open terminal and run: ./setup.sh

OPTION 2 - Manual Setup:
========================
1. Open terminal/command prompt in this folder
2. Run: pip install -r requirements.txt
3. Run: python app.py
4. Open browser: http://localhost:5001

OPTION 3 - VS Code:
==================
1. Open this folder in VS Code
2. Open terminal in VS Code (Ctrl+`)
3. Run: pip install -r requirements.txt
4. Run: python app.py
5. Open browser: http://localhost:5001

🛠️ TROUBLESHOOTING:
===================
If you get errors:
1. Make sure Python 3.7+ is installed
2. Try: python -m pip install --upgrade pip
3. Try: pip install Flask Flask-SQLAlchemy qrcode[pil] Flask-Login
4. Make sure port 5001 is free
